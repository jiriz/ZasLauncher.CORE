# Ikona ZasLauncher 1.0.0.21

Jarka (Codex), 25. 9. 2026. Jiří schválil náhled s logem ZAS a dvojicí
obrazovek pro vzdálené připojení v pravém dolním rohu.

- Zdrojový schválený obrázek: `ZasLauncherGUI/Assets/launcher.png`.
- `Assets/zasgroup.ico` obsahuje velikosti 16, 24, 32, 48, 64, 128 a 256 px;
  používá ho systémová lišta macOS i Windows včetně obnovení menu.
- Stejná ikona je nastavena oběma oknům a Windows EXE přes ApplicationIcon.
- `zasgroup.icns` obsahuje standardní macOS velikosti včetně Retina.
- Verze aplikace: 1.0.0.21.

Ověření: Release publish macOS arm64 a Windows x64 prošel; macOS app bundle
má novou ICNS, verzi 1.0.0.21 a ověřený ad-hoc podpis. Běhová kontrola Windows
lišty nebyla na Macu provedena. Existující upozornění kompilátoru zůstávají.

Výstupy mimo iCloud:

- `/Users/jiriz/ZasLauncher-builds/1.0.0.21/win-x64/ZasLauncherGUI.exe`

Pro změnu ikony běžící systémové lišty je třeba ukončit starý Launcher a spustit

## Oprava 1.0.0.22

Jiří doložil bílé pozadí ikony v liště a původní logo v Docku po otevření
RDP Manageru. Nainstalovaná aplikace měla verzi 1.0.0.21 a SHA-256 její ICNS
byl shodný s novým souborem v repozitáři. Samotná náhrada ICNS tedy nestačila
pro doložené zobrazení Docku; přesná příčina systémové cache nebyla prokázána.

- PNG, všechny velikosti ICO a ICNS mají nyní průhledné pozadí.
- Při zobrazení Docku nastavuje MacDockIcon přímo NSApplication.applicationIconImage
  z vloženého PNG. Nepřebírá případnou starší ikonu z cache aplikace.
- NSImage a NSData se po předání aplikaci uvolní pomocí release; připnutí pole
  se uvolní ve finally. NSApplication si uchovává vlastní referenci.
- Release publish macOS arm64 i Windows x64 a kontrola podpisu Mac app prošly.
- AppKit ověřil alpha kanál, nulovou neprůhlednost všech čtyř rohů a platné
  dekódování PNG do NSImage. Aktivní uživatelská aplikace nebyla restartována;
  vzhled běžící lišty/Docku zbývá ověřit po spuštění této verze.
