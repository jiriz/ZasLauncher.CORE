# Ikona ZasLauncher 1.0.0.21

Jarka (Codex), 25. 9. 2026. Jiří schválil náhled s logem ZAS a dvojicí
obrazovek pro vzdálené připojení v pravém dolním rohu.

- Zdrojový schválený obrázek: `ZasLauncherGUI/Assets/launcher.png`.
- `Assets/zasgroup.ico` obsahuje velikosti 16, 24, 32, 48, 64, 128 a 256 px;
  používá ho systémová lišta macOS i Windows včetně obnovení menu.
- Stejná ikona je nastavena oběma oknům a Windows EXE přes ApplicationIcon.
- `zasgroup.icns` obsahuje standardní macOS velikosti včetně Retina.
- Verze aplikace: 1.0.0.21.

Ověření: Release publish macOS arm64 a Windows x64 prošel; macOS app bundle
má novou ICNS, verzi 1.0.0.21 a ověřený ad-hoc podpis. Běhová kontrola Windows
lišty nebyla na Macu provedena. Existující upozornění kompilátoru zůstávají.

Výstupy mimo iCloud:
- `/Users/jiriz/ZasLauncher-builds/1.0.0.21/ZasLauncher.app`
- `/Users/jiriz/ZasLauncher-builds/1.0.0.21/win-x64/ZasLauncherGUI.exe`

Pro změnu ikony běžící systémové lišty je třeba ukončit starý Launcher a spustit
novou verzi. Aktivní RDP relace nebyly při přípravě sestavení přerušeny.
